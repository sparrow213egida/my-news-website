# Family Calendar

Веб-приложение для отображения семейного расписания из Google Calendar с возможностью оставлять комментарии без регистрации.

---

## Стек

- **Python 3.10+**
- **Flask** — веб-фреймворк
- **Google Calendar API** — получение событий
- **SQLite** — хранение комментариев
- **Jinja2** — шаблонизация
- **python-dotenv** — управление переменными окружения

---

## Установка и запуск

Клонируйте репозиторий и установите зависимости:

```bash
git clone <url>
cd family-calendar
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate
pip install -r requirements.txt
```

Создайте файл `.env` в корне проекта:

```
SECRET_KEY="ваш_секретный_ключ"
```

Настройте доступ к Google Calendar:

1. Зарегистрируйте приложение в Google Cloud Console
2. Включите Google Calendar API
3. Создайте OAuth 2.0 Client ID (тип "Desktop app")
4. Скачайте `credentials.json` и поместите в корень проекта

Запустите приложение:

```bash
python app.py
```

Откройте `http://127.0.0.1:5000` в браузере.

При первом запуске откроется страница авторизации Google — войдите в аккаунт, календарь которого хотите показывать. Файл `token.json` сохранится автоматически.

## Функциональность

### Расписание

Главная страница показывает события на три временных периода:

- **День** — события текущей даты
- **Неделя** — события с понедельника по воскресенье текущей недели
- **Месяц** — события с 1-го по последнее число текущего месяца

Время отображается в московском часовом поясе (UTC+3).

### Комментарии

Пользователи могут оставлять комментарии без регистрации, указав имя и текст. Комментарии сохраняются в SQLite и отображаются под расписанием в хронологическом порядке.

При ошибках (пустое имя, слишком длинный текст) пользователь видит понятное сообщение через flash-уведомления. Форма защищена от спама с помощью honeypot-поля.

## Структура проекта

| Файл | Назначение |
|------|------------|
| `app.py` | Основной файл приложения — маршруты, интеграция с Google API, обработка форм |
| `database.py` | Работа с SQLite — создание таблицы, добавление и получение комментариев |
| `templates/index.html` | Главная страница — отображение расписания, комментариев и формы |
| `requirements.txt` | Зависимости проекта |
| `credentials.json` | OAuth-учётные данные Google (не публикуется в репозитории) |
| `token.json` | Токены доступа (генерируется автоматически) |
| `.env` | Переменные окружения (секретный ключ) |

---

## Обработка ошибок

- Ошибки Google API перехватываются и возвращают понятное сообщение вместо падения сервера
- Пустые или слишком длинные поля комментариев отклоняются с пояснением
- Ошибки базы данных логируются и возвращают сообщение пользователю
- Отсутствие событий обрабатывается как пустой список (без ошибки)

---

## Особенности реализации

- Авторизация в Google выполняется один раз через OAuth 2.0, токены автоматически обновляются
- Запросы к календарю используют параметризованные временные границы для точной фильтрации
- SQL-запросы защищены от инъекций через параметризацию
- Flash-сообщения обеспечивают обратную связь без перезагрузки страницы
- Переменные окружения изолируют секретные данные от кода
